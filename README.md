# Loading

A curated showcase of loading states, progress patterns, system feedback, and motion experiments by [Dani Asyrofi](https://daniasyrofi.com).

**Live site:** [loading.daniasyrofi.com](https://loading.daniasyrofi.com)

## Collections

- Indeterminate activity
- Determinate progress
- System feedback
- Agent activity
- Physical process
- Experimental

The initial release is intentionally showcase-first. Package installation and component-registry distribution are not part of this version yet.

## Local development

No dependencies or build step are required.

```bash
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).

## Project structure

```text
assets/       Shared font and identity assets
posters/      Curated static specimen previews
specimens/    Interactive loading experiments
app.js        Showcase collections and navigation
catalog.json  Public specimen metadata
```
