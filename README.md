# Loading (`loading.daniasyrofi.com`)

> **A curated loading-state design library for discovering, understanding, customizing, and shipping better loading experiences.**

Inspired by high-precision creative motion engineering, **Loading** is not an asset dump or generic spinner generator. It is a comprehensive design system and component registry encompassing both **Visual Indicators** (from zero-dep CSS to AI thinking orbs and WebGL shaders) and **Loading Experiences** (progressive stream verification, checkpoint commits, and zero-layout-shift content handoff).

---

## 🌟 Key Pillars

1. **Discover:** Filter 24 curated specimens across 5 distinct tiers (*Essential, AI & Agent, Expressive, Loading Experiences, Experimental*).
2. **Customize:** Live interactive control knobs (speed, scale, particle density, color palettes, glow bloom) with instant 60/120fps feedback.
3. **Implement:** Copy-source first (React TSX, Vanilla JS, CSS Only) or install via the official **Shadcn CLI**.
4. **Learn:** In-depth mathematical breakdowns, trigonometry formulas, state semantics, and accessibility contracts.

## 🛠️ Engine Selection Principle

> *"Use the cheapest rendering technology that can truthfully create the intended effect."*

```
CSS / DOM → SVG → Canvas2D → WebGL
```

- **Zero Global Dependencies:** The showcase shell and catalog load with 0KB heavy animation libraries.
- **Offscreen Pausing:** All active Canvas/WebGL instances pause automatically when scrolled offscreen or when switching tabs.
- **DPR Capped:** Device Pixel Ratio is strictly capped at 2.0× for Canvas2D and 1.5× for WebGL to ensure 60fps mobile stability without battery drain.
